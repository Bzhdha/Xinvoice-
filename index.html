Cas d'usage AFNOR NF Z55-500

Explorez les workflows métier, les obligations par profil et les étapes selon votre rôle — même sans déposer de facture.

Guide d'utilisation

📂 Déposer une facture

  1. Glissez un fichier PDF FacturX ou XML CII dans la zone de dépôt
  2. L'analyseur extrait automatiquement l'XML embarqué dans le PDF
  3. Tous les champs BT/BG sont identifiés et affichés
  4. Un rapport de conformité est généré selon le profil déclaré (BT-24)

🔍 Comprendre les résultats

  • ✓ Vert — Champ présent et renseigné
  • ✕ Rouge — Champ obligatoire manquant
  • ⚠ Orange — Champ conditionnel absent
  • – Gris — Non applicable dans ce profil
  • ○ Bleu — Optionnel, non renseigné

💼 Cas d'usage et workflows

L'onglet Cas d'usage vous permet de :

  • Sélectionner un cas métier (B2B, avoir, autoliquidation…)
  • Choisir votre rôle (vendeur, acheteur, comptable, PDP)
  • Indiquer l'état actuel de la facture
  • Voir les prochaines étapes personnalisées avec checklists

📋 Champs BT / BG

La norme définit :

  • BT (Business Term) — un champ de données unitaire
  • BG (Business Group) — un regroupement de champs liés
  • Chaque BT a un niveau par profil : M obligatoire, C conditionnel, O optionnel, N non applicable

🔐 Confidentialité

Tout le traitement est effectué localement dans votre navigateur. Aucune donnée n'est transmise à un serveur. Vos factures ne quittent pas votre poste.

ℹ️ Formats supportés

  • PDF FacturX (versions 1.0, 1.0.06) avec XML CII embarqué
  • PDF ZUGFeRD (versions 1.0, 2.0, 2.1) – CII
  • XML CII (Cross-Industry Invoice, UN/CEFACT)
  • XML UBL – extraction basique (informations principales)
