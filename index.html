Guide d'utilisation

📂 Déposer une facture

  1. Glissez un fichier PDF ou XML dans la zone de dépôt
  2. Les données sont extraites automatiquement depuis le fichier
  3. Toutes les informations de la facture sont identifiées et affichées
  4. Un rapport de conformité est généré selon le format de la facture

🔍 Comprendre les résultats

  • ✓ Vert — Renseigné ✓
  • ✕ Rouge — Information requise manquante
  • ⚠ Orange — Non renseigné (facultatif selon le contexte)
  • – Gris — Sans objet pour ce type de facture
  • ○ Bleu — Non renseigné

💼 Cas d'usage et workflows

L'onglet Cas d'usage vous permet de :

  • Sélectionner un cas métier (B2B, avoir, autoliquidation…)
  • Choisir votre rôle (vendeur, acheteur, comptable, PDP)
  • Indiquer l'état actuel de la facture
  • Voir les prochaines étapes personnalisées avec checklists

📋 Informations de la facture

Chaque information est classée selon son importance :

  • Obligatoire — doit être présente dans tous les cas
  • Conditionnelle — requise selon le type de transaction
  • Optionnelle — facultative, enrichit la facture si renseignée
  • Sans objet — non applicable pour ce format de facture

🔐 Confidentialité

Tout le traitement est effectué localement dans votre navigateur. Aucune donnée n'est transmise à un serveur. Vos factures ne quittent pas votre poste.

ℹ️ Formats supportés

  • PDF FacturX (versions 1.0, 1.0.06) avec XML CII embarqué
  • PDF ZUGFeRD (versions 1.0, 2.0, 2.1) – CII
  • XML CII (Cross-Industry Invoice, UN/CEFACT)
  • XML UBL – extraction basique (informations principales)
